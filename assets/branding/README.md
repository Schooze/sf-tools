# Branding assets

Source artwork for the SF-Tools application icon and SF-Motion logo/wordmark variants.

- `app-icon.svg`: source artwork for the application icon.
- `sf-motion-logo.svg`: logo with its original background.
- `sf-motion-logo-transparent.svg`: logo with a transparent background.
- `sf-motion-wordmark.svg` and `sf-motion-wordmark-alternate.svg`: original wordmark variants.
- `sf-motion-wordmark.png`: raster wordmark reference.

Windows application icons used by Tauri are in `src-tauri/icons/`. The application currently
renders its interface emblem through `src/components/common/SfLogo.tsx`.
